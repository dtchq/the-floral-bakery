## 🚀 Features
- **14-Section CRO Homepage Structure**: High-converting hero, category showcase, bestseller carousel with dynamic filtering, customer reviews, local Nashik delivery zone map, and VIP newsletter signup.
- **Modern Vector SVG Logo Suite**: Clean, minimalist botanical bloom branding in vector SVG for ultra-sharp Retina rendering.
- **Interactive Cart Drawer**: Real-time item additions, +/- quantity controls, free delivery progress tracker to ₹999, promo code discount system (`FLORA10`), and direct **WhatsApp Instant Checkout**.
- **Custom Cake Builder Modal**: Bespoke consultation inquiry generator for occasion, weight, flavors, and floral palettes.
- **Pure Vegetarian / 100% Eggless Certified**: Built for celebratory gifting and dietary reassurance.
